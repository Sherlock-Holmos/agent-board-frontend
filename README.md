# 待办系统 (Todo Board)

基于 Vue 3 + TypeScript + Element Plus 构建的待办事项管理系统。


## 功能特性

- ✅ 任务管理（添加、完成、删除、编辑）
- 📅 按日期分类（今天、最近7天、所有）
- 📋 清单分类（收集箱等）
- 🎨 日期状态标注：当日蓝色、未来绿色、逾期红色
- 🤖 Agent 对话与画像面板（多轮推理、快捷指令、上下文展示）
- ⚡ 输入框 Agent 快捷指令（本地极速解析 + 自动创建）
- 🗂️ 四象限视图（重要紧急任务优先级管理）
- ⏲️ 番茄钟计时与统计
- 🗑️ 编辑面板支持直接删除
- 🚀 响应式布局

## 技术栈

- **Vue 3** - 渐进式 JavaScript 框架
- **TypeScript** - 类型安全的 JavaScript
- **Element Plus** - Vue 3 组件库
- **Pinia** - 状态管理
- **Vite** - 构建工具

## 使用说明

1. **添加任务**：在输入框中输入任务标题，按回车键添加
2. **完成任务**：点击任务前的复选框标记为完成
3. **编辑/删除任务**：打开任务详情或编辑对话框后，可直接删除
4. **切换视图**：点击左侧导航栏中的不同选项（所有、今天、最近7天、收集箱）
5. **折叠任务组**：点击日期标题旁的箭头图标可折叠/展开任务组
6. **日期颜色提示**：当日蓝色、未来绿色、逾期红色


## Agent 智能助手

Agent 负责理解自然语言并加速任务管理，包含“快捷输入”和“对话面板”。

### 1) 输入框 Agent 快捷输入

- 右侧开启 Agent 开关后，输入自然语言会快速创建待办
- 支持相对日期：今天 / 明天 / 后天
- 支持日期格式：2026-01-22、1月22日、22号
- 若输入内容与已有任务标题完全一致，会优先执行删除（用于快速清理）
- 示例：
	- 22号我要回家 → 创建 1月22日「回家」
	- 删除 项目答辩 → 删除同名任务

### 2) Agent 对话面板

- 对话面板支持更复杂的提问与批量操作
- 支持多轮对话、上下文记忆、快捷指令（如“生成周报”、“安排提醒”）
- 画像面板展示“特征气泡 + 一句话总结”，可一键清空
- 画像存储在浏览器本地（localStorage），关闭窗口后仍保留

### 3) 四象限与番茄钟

- 四象限视图：可视化任务优先级，支持一键切换
- 番茄钟：计时、统计、历史记录，助力专注



## 系统架构

本前端项目采用模块化设计，核心架构如下：

- **组件层**：所有 UI 组件集中于 `src/components/`，如 Sidebar（导航）、MainContent（主内容）、AgentDialog（对话面板）、PomodoroView（番茄钟）等，支持复用与独立开发。
- **状态管理**：使用 Pinia 进行全局状态管理，`src/stores/` 统一管理任务、用户、设置等数据。
- **接口层**：`src/api/` 封装所有与后端的 HTTP 通信，便于统一维护和扩展。
- **工具层**：`src/utils/` 提供本地存储、数据处理、Agent 画像等工具函数。
- **类型定义**：`src/types/` 统一管理 TypeScript 类型，提升类型安全和开发效率。
- **页面视图**：`src/views/` 组织各业务页面，便于路由和页面级扩展。

前端通过 RESTful API 与后端服务交互，Agent 相关功能通过专用接口实现多轮对话、快捷指令和画像管理。

## 开发与扩展建议

- 推荐使用 TypeScript 进行类型约束，提升代码健壮性。
- 新增功能建议以组件为单位开发，便于维护和复用。
- 状态变更统一通过 Pinia 管理，避免组件间数据混乱。
- Agent 相关能力可通过扩展 `src/api/agent.ts` 和 `src/components/agents/` 实现。
- 如需适配移动端，可调整样式和布局，或引入响应式方案。
- 详细注释和接口文档建议同步维护，便于团队协作和二次开发。
